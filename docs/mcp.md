# Plano як MCP-сервер (для ChatGPT, Claude та інших помічників)

Помічник підключається до вашого планера й виконує команди людською мовою: «постав на завтра о 15 зустріч з Олею»,
«що в мене сьогодні?», «відміть купівлю ліків», «запиши в нотатку підсумки». Сервер живе в тому самому Cloudflare Worker,
що й Google Calendar та сповіщення (`worker/src/mcp/`), і працює від імені **одного власника**.

## Що вміє

| Інструмент | Що робить |
|---|---|
| `planner_info` | Дата й час зараз, **точні назви ваших категорій і проєктів**, що означають пріоритети. Помічник викликає його першим. |
| `add` | Додає **задачі, події, нотатки** з явними полями: назва, дата, час, тривалість, **проєкт, категорія, пріоритет**, теги, підзадачі, повторення, нагадування. Або з рядка тексту тим самим розбором, що й швидкий запис у застосунку. Кілька записів за раз. |
| `today` | Прострочене, задачі й події на сьогодні, звички дня. |
| `list_tasks`, `list_events` | Списки з фільтрами (дати, текст, проєкт, категорія); повторювані події розгорнуті. |
| `complete_task`, `reopen_task` | Виконати чи повернути; повторювана задача отримує наступну копію, як у застосунку. |
| `update_task`, `update_event` | Перейменувати, перенести, час, тривалість, місце, **проєкт, категорія, пріоритет**, опис. |
| `delete_task`, `delete_event` | Видалення (тільки за точним id; помічник має спитати вас). |
| `search_notes`, `get_note`, `add_note`, `append_to_note` | Нотатки (Markdown); кошик не показується. |
| `list_habits`, `log_habit` | Звички дня й відмітка. |

**Пріоритети:** `low` = не терміново, `medium` = звичайна (за замовчуванням), `high` = важливо, `urgent` = терміново.
Помічник ставить пріоритет лише коли у ваших словах він є («терміново», «важливо»).
**Проєкт чи категорія, яких не існує, не вгадуються:** помічник отримує помилку зі списком наявних назв і виправляє виклик.

Усі записи проходять ті самі перевірки (zod-схеми), що й у застосунку. Подія, створена помічником, потрапляє в Google Calendar,
якщо він підключений (її позначає `syncPending`, а відправляє застосунок, коли відкритий).

## Налаштування (один раз)

Сервер **вимкнений**, доки не задано три секрети (без них він навіть не відповідає на ці адреси).

1. **Сервісний акаунт Firebase.** Google Cloud Console → IAM → Service accounts → створіть окремий акаунт `plano-mcp`
   із роллю **Firebase Realtime Database Admin** (лише вона) → Keys → Add key → JSON. Файл — це ключ: нікому не показуйте,
   не кладіть у репозиторій і не вставляйте в чат.
2. **Ваш uid.** Firebase Console → Authentication → Users → колонка **User UID** вашого акаунта.
3. **Пароль доступу** — довга фраза (мінімум 16 символів, краще 30+), яку ви введете один раз на сторінці дозволу.
4. **GitHub → Settings → Secrets and variables → Actions → New repository secret:**
   - `FIREBASE_SERVICE_ACCOUNT` — увесь вміст JSON-файлу;
   - `MCP_OWNER_UID` — uid з кроку 2;
   - `MCP_OWNER_SECRET` — пароль з кроку 3.
5. Запустіть деплой (push у `main` або Actions → Run workflow). Адреса сервера: `https://plano-gcal.<ваш піддомен>.workers.dev/mcp`
   (піддомен видно в журналі кроку «Worker URL»; адресу також показує «Налаштування → Інтеграції»).

## Підключення в ChatGPT

Налаштування → Apps/Connectors → увімкніть режим розробника → **Add custom MCP server** → вставте адресу `…/mcp`,
автентифікація **OAuth** (вона знайдеться сама). ChatGPT відкриє сторінку «Plano — дозвіл»: введіть пароль з кроку 3.
Далі просто пишіть: «додай до Plano …». Дії, що змінюють дані, ChatGPT може підтверджувати запитом.
Які можливості доступні, залежить від плану ChatGPT (для окремих планів інструменти запису можуть бути недоступні).

Claude Code: `claude mcp add --transport http plano https://plano-gcal.<піддомен>.workers.dev/mcp`, потім `/mcp` → Authenticate.

## Безпека

- Вхід — OAuth 2.1 з PKCE; жодного стану на сервері: коди й токени підписані ключем, виведеним із `MCP_OWNER_SECRET`.
  Токен доступу живе годину, оновлення — 60 днів.
- **Відкликати все** (втрачений телефон, підозра): змініть `MCP_OWNER_SECRET` у GitHub Secrets і задеплойте — усі токени одразу недійсні.
- Неправильний пароль на сторінці дозволу коштує секунду очікування; тому пароль має бути довгим.
- Сервер працює лише з даними свого uid і не вміє нічого, крім перелічених інструментів.
- Усе, що помічник читає, потрапляє в модель. Не підключайте помічників, яким не довіряєте.
- Видалення потребує точного id: помічник спершу має знайти запис.
